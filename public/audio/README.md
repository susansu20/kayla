# Audio

Drop a royalty-free instrumental at `birthday-loop.mp3` (in this folder).

Recommended:

- Bensound — "Memories" or "Tenderness" (https://www.bensound.com)
- Pixabay Music — search "Birthday Celebration" (https://pixabay.com/music)

The track starts at 35% volume and loops. The floating mute pill (bottom-right)
controls it from Act 2 onward.
